Real-Time Process Monitoring is a Python-based monitoring dashboard that provides live insights into system processes and resource usage.

It displays CPU, memory, and running process information in real time through an interactive Streamlit dashboard.

---

## 🚀 Features

- 📊 Real-time CPU monitoring
- 💾 Memory usage tracking
- ⚙️ Live running process table
- 🔍 Process filtering and analysis
- 📈 Interactive dashboard UI
- 🌐 Streamlit web deployment

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Psutil
- Pandas
